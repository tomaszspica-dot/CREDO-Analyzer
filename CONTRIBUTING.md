# Contributing

Contributions should preserve source provenance and scientific
traceability.

Before submitting changes:

- read `AGENTS.md`
- read `CODE_PROVENANCE.yaml`
- do not commit runtime data
- do not remove third-party notices
- keep unrelated refactoring separate
- test Python syntax
- test JavaScript syntax where Node.js is available
- document changes affecting scientific calculations or classifications

Changes to third-party code must update the corresponding provenance
record.
